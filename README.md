# Artemesia

An open research project for documenting *Artemisia* species, their taxonomy, distribution, ecology, and traditional or contemporary uses.

> Note: the repository name follows the requested spelling, `artemesia`; the plant genus is conventionally spelled *Artemisia*.

## Project scope

- Build a source-backed catalog of *Artemisia* species.
- Record accepted names, synonyms, identifiers, and geographic ranges.
- Track ecological traits, conservation context, and documented uses.
- Keep claims linked to authoritative sources and mark uncertainty clearly.

## Repository layout

```text
data/       Structured species records (to be added)
docs/       Project notes, methods, and contribution guidance
sources/    Source notes and citation metadata (to be added)
```

## Status

Project initialized. The schema and first species records are the next milestones.

## Contributing

Add one species at a time, cite every factual field, preserve the source's taxonomic scope, and distinguish reported use from demonstrated efficacy.
