# Submission-readiness checklist

## Scientific completeness

- [x] Mono- and sesquiterpene classes reviewed.
- [x] Diterpene and triterpene coverage included with an explicit evidence limitation.
- [x] Sesquiterpene-lactone chemistry, artemisinin, and analytical constraints included.
- [x] Biosynthetic pathways and gene-family evolution addressed.
- [x] Chemotype, tissue, phenology, environment, extraction, and analytical variation addressed.
- [x] Antiparasitic assay evidence includes parasite stage and mixture-level limitations.
- [x] Safety and translation boundaries included.
- [x] Testable hypotheses and discriminating experiments included.

## Evidence and reporting still required before journal submission

- [x] Run and archive the initial PubMed database searches and result counts.
- [x] Archive a high-cap retrieval and cross-query deduplication summary.
- [ ] Deduplicate records and archive excluded records with reasons.
- [ ] Replace seed-set-only language with a completed screening statement.
- [ ] Verify every quantitative claim against the primary source and specimen context.
- [ ] Complete author/year/journal/volume/pages/DOI metadata in `references.bib`.
- [ ] Add a final PRISMA-style flow diagram if the review is submitted as systematic or scoping.
- [ ] Add a supplementary compound-by-specimen table once extraction is complete.
- [ ] Resolve *A. argyi* ADS/TPS annotation differences across assembly releases.
- [ ] Pin software versions, scripts, manifests, and checksums for comparative-genomics analyses.
- [ ] Obtain journal-specific formatting, data-availability, conflict-of-interest, and ethics statements.

The checked items describe the current draft; unchecked items are not silently treated as complete.
